# 人物动画与尺寸调整（2026-11-19）

接入美术提供的两张 380×400 透明 PNG，睁眼为 idle.png，闭眼为 blink.png，保存在 assets/actors/office_character/。原图保持原尺寸，运行时使用最近邻过滤、等比例缩放。

## 当前规格

- 当前房间为 1280×704。人物外观高 48 游戏单位，约占画面高度 6.82%，画布宽约 45.6。
- 玩家碰撞矩形由 28×38 改为 32×44，碰撞形状中心为 (16, 22)。
- 人物画布相对角色节点偏移约 (-6.8, -4)，脚底与碰撞框底部对齐。
- Echo 的 body_size 同步为 32×44，头顶单向薄片为 32×8。
- 待机眨眼周期为 3 秒，闭眼约 0.15 秒。当前移动和跳跃也使用这两帧。
- Echo 使用相同人物贴图，青色半透明表现。眨眼是表现层计时，不记录进轨迹。
- level_01 的出生高度调整到 516。complete_room、office_build 和 graybox/base_level 的出生高度调整到 532，避免增高后插入地面。

此比例根据用户提供截图的主要身体占比近似选择。外观与物理尺寸分开设置，头发和装饰允许伸出碰撞范围。

## 实现位置

- scripts/character_portrait.gd：两帧切换、等比例缩放、脚底对齐及 Echo 色调。
- scripts/player.gd：对人物 Sprite 调用 fit_to_body，其他图形继续使用原缩放路径。
- scripts/echo.gd：人物 Body 使用同一对齐接口，碰撞体积与贴图保持解耦。
- scenes/player/player.tscn、scenes/echo/echo.tscn：挂接人物表现脚本和调整碰撞形状。

## 验证

```
godot --headless --path . --fixed-fps 60 --script res://_reference/tools/test_character_portrait.gd
godot --headless --path . --fixed-fps 60 --script res://_reference/tools/test_complete_room.gd
godot --headless --path . --fixed-fps 60 --script res://graybox/tests/test_graybox_kit.gd
```

覆盖动画切帧、暂停时动画冻结、外观比例、脚底与地面、Echo 体积、完整谜题流程、伤害重生和灰盒机关。实际渲染截图为 docs/images/character-preview.png。F1 可开关碰撞调试框。
