## 4. 两条风格路线，得选一条

**路线 ①「克制写实 / 工业」**（推荐，A+B+C+D+E+F）
门是滑门不是木门，脚踩的是地砖，音色偏闷、偏干。和现在 `#101720` 的深蓝灰背景、琥珀色门、薄荷色出口是同一套情绪。
缺点是"游戏感"弱一点，需要靠形变和镜头补反馈。

**路线 ②「8-bit 芯片」**（H+I，可混 F）
方波，一听就是"像素游戏"。好处是包内齐全、跳跃/受伤/菜单一个包解决，风格绝对统一。
缺点：方波的高频会把现在这种安静、略忧郁的调子打破。如果走这条，建议只让**机关和 UI** 用 8-bit，跳跃/落地仍走 ①。

**我的建议**：走 ①，跳跃用 F。理由是这套美术（深蓝灰 + 琥珀 + 薄荷，人物 380×400 像素插画风）更像"安静的解谜"，不像"街机"。

## 5. 确认后我会怎么做

1. 只下 A/B/C/D/F 五个包，解压到临时目录，挑出 **14 条**，转成 `assets/audio/sfx/*.ogg`（Godot 原生吃 ogg/wav，不重编码）。
2. 新建 `assets/audio/LICENSE.md` 记录每个文件的来源、作者、许可、原始 URL——以后要换素材也有据可查。
3. 加一个 `AudioManager` autoload（`scripts/audio_manager.gd`），只做三件事：`play(name, pitch_jitter)`、限流（同一帧不重复播）、`SFX` 子总线（音量跟现有的 Master 滑杆走）。
4. 在 12 个槽位接上调用（player / plate / door / exit / UI）。
5. 补一个 `test_audio.gd`：断言 12 个音频文件能加载、每个 slot 都有对应文件、`AudioManager` 不重复播。

## 8. 版权核查结论（2026-11-20）

前置事实：**OpenGameArt 的许可证是上传者自己在下拉框里选的，OGA 不做版权审查**；
Kenney 是公司化运作、官网自营。所以"页面写着 CC0"不等于"上传者有权 CC0 它"。
判断一条素材能不能用，看三件事：上传者是不是作者本人 / 有没有能自证制作的源文件 / 网络上有无同名付费商品。

> 以下是基于公开信息的尽调，不是法律意见。

| 包 | 页面标注 | 上传者＝作者？ | 独立证据 | 裁定 |
|---|---|---|---|---|
| C Kenney Impact Sounds | CC0 | 是，官网自营 | 每个资产页逐页标 CC0，包内附 license.txt | ✅ 直接可用 |
| D Kenney UI Audio | CC0 | 是 | 同上 | ✅ 直接可用 |
| E Kenney Interface Sounds | CC0 | 是 | 同上 | ✅ 直接可用 |
| I Junkala 512 SFX | CC0 | 是（SubspaceAudio 本人主页） | 同一作者的 itch 商业包（1000 / 6000 条）同源，免费版是引流 | ✅ 直接可用 |

### 结论

真正"零义务、零疑点"只有 **C / D / E / H / I** 五个（Kenney 三个 + Junkala + MoxieCat）。
A / B / F 都是 CC0 但授权链有瑕疵，B / F 建议直接换掉：

- **F（跳跃）** → 换 Junkala 512 里的 `jump_*`（CC0、作者本人），跳跃是最高频音，不能挂在存疑素材上。
- **B（金属木）** → 换 Kenney Impact Sounds 的 `impactMetal_*` / `impactWood_*`（每个 5 变体，量比 B 更大，且零疑点）。
- **A（门/落地/脚步）** → 只有"滑门轨道音"和"地砖脚步"是 Kenney 没有的。两个选择：
  - 接受 A（低风险，CC0 声明清晰、八年无人主张）；
  - 或全绿路线：门用 Kenney `impactMetal_heavy` + 低音层拼出"砸下"，代价是门不再"滑"，脚步直接不做。

### 技术层面：能直接拖进 Godot 吗

能，但有三件事必须处理，否则"能用"会变成"用起来怪"：

1. **格式**：Kenney 给 `.ogg`，OGA 给 `.wav`。Godot 4 两者都原生支持，**不需要转码**。
2. **导入设置**：Godot 默认 `Loop = Detect`，短音效有可能被判成循环，必须改成 `Disabled`；SFX 压缩用 `PCM`。这一步不设，开门声会一直响。
3. **响度不统一**：五个包的电平差 6~12 dB，直接播会出现"跳跃比门还响"。要在 `AudioManager` 里给每个槽位一个基准 `volume_db`，而不是统一 0 dB。

### 留痕（防日后被质疑）

每个用到的文件在 `assets/audio/LICENSE.md` 里记四件事：原始 URL、作者、许可、下载日期。
CC0 不需要署名，但**保留证据**和"是否署名"是两件事——真被平台或发行方问到，能拿出页面截图和日期就没事。
