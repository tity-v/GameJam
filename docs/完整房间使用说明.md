# 可通关房间

F5 启动 `scenes/levels/complete_room.tscn`。固定镜头显示一个 1280×720 的房间。

## 解法

走到 A 压力板，等待约 4 秒，再按 E。复活后向 B 移动。Echo 重放上一轮并踩住 A，当前玩家踩住 B，两板同时激活，门锁存打开。之后走进右侧出口完成关卡。通关画面可点按钮或按 R 再玩。出生点左侧尖刺可验证伤害与死亡重生。

## 规则

- Echo 沿用坐标轨迹重放、上限 5 个、FIFO 替换、播放后 1.3 秒淡出。
- 机关检查 Echo 完整身体的脚底范围，与头顶用于垫脚的薄片碰撞分开。
- 活着的当前玩家和有效 Echo 均可踩板。消失后不再触发。
- 本关门需要两块板同时激活，之后保持打开；按 R 不会把它关回去（门是锁存的）。
- 只有当前玩家能触发出口，出口要求门已打开。
- 尖刺伤害当前玩家。Echo 的死亡时刻沿用录制时间轴。
- 按 R = **只清空 Echo + 玩家回出生点**，机关状态保留：门开了仍然开着，板上的 Echo 没了于是自动松开。
  想整关重来用通关面板上的 Replay（它才调 `room_controller.reset_room()` 重载场景）。
- 全部关卡共用同一套 R 行为；完整重置入口只剩 `room_controller.reset_room()`，只有 Replay 会调。

## 搭建和接口

- `office_build.tscn` 可用于纯地形试搭。
- `complete_room.tscn` 是含玩家、Echo、机关和结算的可玩模板，可另存为新关卡。
- `Ground_PaintHere` 画实体瓦片，`Decor_NoCollision` 画背景瓦片。
- `plate_off.tscn` 根节点设置 `block_size`、`accepts_player`、`accepts_echo`。
- `door.tscn` 根节点在 `plate_paths` 中关联压力板，`latch_open` 控制锁存。空列表保持关闭。
- `exit.tscn` 用 `door_path` 指定门，进入后调用关卡的 `complete()`。
- `spike_tile.tscn` 调整 `block_size` 设置尖刺范围。
- 完整重置由 `room_controller.reset_room()` 处理，EchoManager 的 R 输入会优先调用它。

## 验证

`godot --headless --path . --fixed-fps 60 --script res://_reference/tools/test_complete_room.gd`

测试从真实按键录制完整一轮，再用一个 Echo 通关。检查单人不可开门、Echo 足部触发、门可通过、出口、R 只清 Echo 且保留机关状态、通关后 R 被忽略、Replay 整关重来、尖刺伤害与重生。图形模式运行同一脚本会输出通关截图。
