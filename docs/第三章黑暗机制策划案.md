# 第三章 · 黑暗与光（策划案 v0.2）

> 一句话：**这一章不给玩家手电筒，给玩家「过去的自己」。**
> 玩家能主动「打火」照亮一小圈，但那圈光**永远够不到跳台**；
> 能照亮落点的光来自虚影——而虚影重放的是你亲手录下的轨迹。
> 于是「录制路线」和「布置光源」变成同一个动作。

状态：**草稿，未实现**。所有数值待原型验证，落地方案见 §7。
参考对象：《蜡烛人》（Candleman，交典创艺 2016），借鉴处与不借鉴处见 §2。

---

## 1. 设计目标

| 目标 | 说明 |
|---|---|
| 给第三章一个新维度 | 第一、二章解决「怎么过去」，第三章解决「我看不见要往哪去」 |
| 不加新系统 | 光源挂在已有的虚影上，不改录制/回放逻辑 |
| 让失败有视觉代价 | 死一次 = 少一条光源，比扣血、扣分更有体感 |
| 主题自洽 | 虚影是记忆，光是记忆照路，与全篇「回声」基调一致 |

**不做的事**：不做燃料总量、不做可收集光源道具、不做黑暗惩罚（视野外不掉血、不刷怪、不加速）。

## 2. 从《蜡烛人》学到什么，不学什么

《蜡烛人》是把「黑暗 + 光」做成核心机制最干净的样本之一。它有三条东西值得抄，一条绝对不能抄。

### 抄第一条：光要是一个「动作」，不是一个「状态」

蜡烛人按扳机键才燃烧，松手就黑。**「要不要点亮」是玩家每分钟做几十次的决策**，而不是开场就给你一片视野。

我们 v0.1 的方案里玩家光是常亮的，等于把这个决策删掉了。改成主动打火——黑暗里你只有轮廓，打火才看得清，而打火有持续时间和冷却（见 §3.2）。

### 抄第二条：「照明 + X」的叠加语法

这是蜡烛人真正的设计方法论：**点亮 → 照明 + X**。第一个大章只有照明，之后每一章给光加一个新反应（发光台阶、花开、驱散幽灵、融冰、用影子操控机关）。

> 主创的说法是「设置不同的简单元素，再删减或者叠加」，全程不增加任何新按键，只让环境对光做出新反应。

这条对我们尤其合适：压力板、门、尖刺、出口全是现成的，只要给它们加一个「对光的反应」，一个新机制就出来了，不需要新按键。

### 抄第三条：最后一关要简单

蜡烛人第六幕最后一关是全森林最简单的一关——此前所有玩法以更低难度重演一遍，用美景奖励玩家，唤起「我成长了」的感受。

我们的 v0.1 把 3-5 写成「综合关 90~120s」，方向反了。**高潮放在 3-4，3-5 做低难度回顾**。

### 不抄：10 秒燃烧总量 = 死亡

蜡烛人的 10 秒是**全关卡总资源**，烧完就 Game Over。它成立是因为那是个慢节奏探索游戏，玩家在「看清」和「活命」之间做长期权衡。

我们是 60fps 精确跳跃解谜：跳跃一旦变成「边算燃料边跳」，认知负荷会直接压垮操作。而且我们已经有「虚影上限 5 条 + 死亡重生」这套惩罚循环，再加一层资源管理就是双重惩罚。

**改成：打火无总量限制，但有节奏限制。** 压力来自「此刻亮不亮」，不是「总共还能亮多久」。

### 顺手拿走的三条细节

| 做法 | 我们怎么用 |
|---|---|
| **烛泪会留下**，成为黑暗中摸索的指引 | 虚影走过的路径留极淡光痕，渐隐——天然的「我探索过这里」地图 |
| **环境教学，零文字提示** | 每间房只教一件事，靠「光照上去会发生什么」自己说话 |
| **黑暗要有颜色**（深蓝底 + 暖黄光），不是纯黑 | 底光用冷蓝、光源用暖黄、虚影光用青，三种光一眼能分清 |

## 3. 核心机制

### 3.1 三层亮度

| 层 | 来源 | 半径 | 玩家感知 |
|---|---|---|---|
| 地形底光 | 场景整体压暗 | — | 看得见「有东西」，看不清「是什么」 |
| 角色底光 | 角色自带，常亮 | 40px | 只够看见脚下一格 |
| 打火光 | 玩家主动点燃 | 96px，2.5s | 看得清地形和机关，但**够不到跳台** |
| 虚影光 | 每条虚影常亮 | 128px | 唯一能照亮落点的光 |

### 3.2 打火：有节奏，无总量

| 状态 | 行为 |
|---|---|
| 点燃 | 按下即亮，半径 40 → 96px，持续 2.5s 后自动熄灭 |
| 熄灭 | 半径回落到 40px，进入 1.5s 冷却 |
| 冷却中 | 不能再点，但仍有 40px 底光（**不会全瞎**，这是关键） |
| 冷却结束 | 可再次点燃 |

周期 4s，亮 2.5s（62%）。一次跳跃 47 帧（0.78s），一次打火完全够用，所以操作上不会卡手；但**连续三次跳跃就要规划打火时机**，压力落在「节奏」而不是「资源」上。

冷却期保留 40px 底光，是为了避免「想点却点不了、屏幕全黑」这种纯挫败。蜡烛人可以让人全黑，因为它节奏慢；我们不行。

### 3.3 一条硬约束决定全部策略

- 本作跳距 **213px（6.6 格）**，满跳 **115.1px**
- 「看得见落点」的门槛是**半跳距 ≈ 106px（3.3 格）**

```
角色底光 40px   < 106  → 永远看不见落点
打火光   96px   < 106  → 单靠自己，永远跨不了台
虚影光  128px   > 106  → 唯一能安全起跳的光
```

**这三行是这一章全部的策略空间。** 玩家再怎么打火也跨不过去，必须等虚影把光带过来——而虚影走哪条路，是你上一轮自己录的。

### 3.4 「照明 + X」：三个环境反应

不给光加新按键，只让已有机关对光做出反应：

| X | 反应 | 用在哪 | 情绪 |
|---|---|---|---|
| **X1 显形** | 隐藏平台只在光照范围内实体化 | 3-3 | 光 = 让不存在的东西存在 |
| **X2 惧光** | 尖刺在光照范围内收起，暗处才升起 | 3-2 | 光 = 安全 |
| **X3 反噬** | 某种尖刺**只在光照范围内**升起 | 3-5 | 光 = 危险（反转） |

X2 和 X3 是同一个开关的两种极性，代码上别写两套。

X3 是全章的情绪高点：你一路靠光走过来，最后一间光变成了威胁。这是蜡烛人「光亮会带来安全感，有时发光也并不安全」那句设计感的直接引用。

### 3.5 光的三个副产物（都是现成机制，零成本）

1. **死亡 = 失去一条光源**。虚影淡出 1.3s，光同步渐弱，视觉上「灯灭了」。
2. **复活 = 灯重新亮起**。全体虚影从第 0 帧重放，光跟着重演一遍，形成节奏。
3. **录制时就在布光**。你想让哪片区域将来是亮的，录制时就得从那里走过。

## 4. 数值配置（待原型验证）

| 参数 | 建议值 | 可调区间 | 设计意图 |
|---|---|---|---|
| 地形底光（`CanvasModulate`） | 亮度 10%，冷蓝调 | 8~12% | 低于 8% 完全失去轮廓，高于 12% 没有黑暗感 |
| 角色底光半径 | 40px | 32~48px | 够看脚下一格，不够判断落点 |
| 打火光半径 | 96px | 88~104px | **必须 < 106px** |
| 打火持续 | 2.5s | 2.0~3.0s | 覆盖 3 次连续跳跃 |
| 打火冷却 | 1.5s | 1.2~2.0s | 冷却中仍有底光，不制造全黑 |
| 虚影光半径 | 128px | 112~144px | **必须 > 106px** |
| 虚影光衰减 | 边缘 30% 亮度 | — | 光有边界感，不是硬切 |
| 虚影光痕 | 停留 1.2s，4s 内渐隐 | — | 走过即留痕，但不能当永久地图 |
| 死亡闪白 | 0.20s | 0.15~0.25s | 让玩家看清自己死在哪 |
| 出口微光 | 常亮，半径 96px | 80~112px | 方向永远可见 |

**色彩基调**：

- 底光用冷蓝（约 `#1A2332`），让黑暗有颜色而不只是黑
- 光源用暖黄（约 `#FFC978`），冷暖对比出质感
- 虚影光偏青（`#9FE1CB`），和玩家暖光区分开——**两种光一眼能分清是谁的**

> 所有数值以探针实测为准，先跑 3-1 再定表。

## 5. 关卡节奏（5 间房，语法逐间叠加）

| 房间 | 底光 | 光的作用 | 新东西 | 时长 |
|---|---|---|---|---|
| 3-1 | 45% | 照明 | 打火、一条现成虚影当路灯 | 30~60s |
| 3-2 | 25% | 照明 + X2 惧光 | 尖刺怕光；两条虚影，光路分叉 | 60~90s |
| 3-3 | 10% | 照明 + X1 显形 | 隐藏平台只在光里存在 | 60~90s |
| 3-4 | 0% | 只有光 | 全黑、无地形轮廓（**一章只此一间**） | 20~40s |
| 3-5 | 15% | 照明 + X3 反噬 + 全章回顾 | 光会让尖刺升起；低难度，重在美感 | 60~90s |

**两条节奏原则**：

1. **黑暗是递进的，不是一上来全黑。** 3-4 是高潮不是基线——连续五间全黑，玩家会从「紧张」变成「烦」。
2. **最后一间要简单。** 3-5 把所有元素以更低难度重演，高潮情绪留给 3-4。

## 6. 可读性四保险（缺一条就会出事故）

| 保险 | 做法 | 防的是什么 |
|---|---|---|
| 出口常亮 | 出口自带微光，不受黑暗影响 | 玩家不知道往哪走 → 原地打转 |
| 冷却期留底光 | 熄灭后仍有 40px，不全黑 | 「想点却点不了」的纯挫败 |
| 死亡闪白 | 死亡瞬间全场亮 0.2s 再黑回去 | 不知道自己死在哪 → 复活后重复试错 |
| 撞墙闪灯 | 虚影被地形截停时，光晕闪一下 | 把「虚影卡住」误判成「灯坏了」 |

> 最后一条是本项目特有的坑：虚影撞墙会**停在接触点**（`_clip_motion` 的既定行为，见 HANDOVER §5）。
> 黑暗中它停住、光也停住，玩家几乎必然误判。闪灯是把原因直接写在表现上。

## 7. 技术实现要点

| 项 | 做法 | 注意 |
|---|---|---|
| 全屏压暗 | 房间根节点挂 `CanvasModulate` | 必须放在房间根下，不能放 `CanvasLayer` 里 |
| 光源 | 角色挂 `PointLight2D`，贴一张径向渐变图 | 不开 `shadow`，省掉给每格瓦片加 `LightOccluder2D` |
| 打火 | 改光源 `energy` 与 `texture_scale`，走 Tween 或 lerp | 冷却状态要能被测试读到，别只写在视觉里 |
| X1 显形平台 | 新增 `LightPlatform`，按与光源距离切换碰撞 | 判定贴 32px 网格，别用像素级距离 |
| X2/X3 光敏尖刺 | 给 `spike_hazard.gd` 加「光敏」开关与极性 | 两种极性一个开关，别写两套逻辑 |
| 光痕 | 虚影每 N 帧落一个 `Sprite2D`，Tween 淡出 | 别每帧都落，5 条虚影会瞬间炸出几千个节点 |
| HUD | 放在 `CanvasLayer` | 与房间不同 canvas，自动不受压暗影响 |
| 换场 | 两间房同时在场上 | `CanvasModulate` 必须走同一个预设，否则滑动时半屏亮半屏暗 |

**已知风险**：光不穿墙（不开 shadow）意味着光会透过墙照亮墙后内容。当前折中方案是「光半径小 + 靠底光给轮廓」，代价是照明不提供遮挡信息。若原型觉得违和，再加遮挡（成本约为每格瓦片一个 `LightOccluder2D`，需评估）。

## 8. 验收标准

能测的才算数，全部走 `--headless --fixed-fps 60`：

1. 角色底光半径 < 半跳距，且在该半径外起跳必然看不见落点
2. **打火光半径 < 半跳距**：单人再怎么打火也跳不上 128 的台子
3. 虚影光半径 > 半跳距，踩着虚影起跳能看见落点
4. 打火 2.5s 后自动熄灭，冷却 1.5s 内不能重燃，冷却中光半径恒为底光值
5. 黑暗中底光下地形轮廓可辨识（截图灰度差 > 阈值）
6. 出口在任何房间的黑暗配置下都能被看见
7. X1 平台在光照范围外无碰撞、范围内有碰撞
8. X2 尖刺在光照范围内不伤玩家，X3 反之
9. 死亡后 0.2s 内全场亮度 ≥ 设定阈值
10. 虚影撞墙时灯光有可见变化
11. 换场滑动期间两间房亮度差 < 5%
12. 场上 5 条虚影 + 玩家打火时帧时间不超 16.6ms

## 附：v0.1 → v0.2 的六处改动

| 改动 | 原因 |
|---|---|
| 玩家光从「被动常亮 64px」改为「主动打火 96px / 2.5s + 冷却 + 40px 底光」 | 学蜡烛人：让「要不要点亮」成为玩家决策 |
| 新增「照明 + X」三个环境反应（显形 / 惧光 / 反噬） | 学蜡烛人的叠加语法，用已有机关，不加新按键 |
| 新增虚影光痕 | 学蜡烛人的「烛泪保留」，且与虚影机制天然同源 |
| 3-5 从「综合关」改为「低难度回顾关」 | 学蜡烛人：最后一关给情感回报，高潮留给 3-4 |
| 明确色彩基调（冷底 + 暖光 + 青虚影光） | 学蜡烛人：黑暗要有颜色，不是纯黑 |
| 明确不抄「10 秒总量」 | 我们是精确跳跃解谜，资源管理会和操作打架 |
