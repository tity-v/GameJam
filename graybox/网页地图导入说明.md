# 网页地图导入

网页导出地图 JSON 后，在 PowerShell 运行下列命令。将 JSON 路径替换为实际文件；输出路径使用新的文件名，导入器遇到已有文件会停止。

```powershell
& 'D:/Projects/Gamejam/本地工具/godot-4.7.2/Godot_v4.7.2-stable_win64_console.exe' --headless --path 'D:/Projects/Gamejam/灰盒隔离工作区' --script res://graybox/import_web_map.gd -- 'D:/下载/地图.json' 'res://scenes/levels/drafts/网页房间.tscn'
```

导入后在 Godot 打开新场景，检查机关关联，再按 F6 试玩。通过「项目 → 工具 → 将当前房间接入章节」安排房间。

导入器按 32 像素每格生成 World 地形、图片和机关。背景块不创建碰撞；门的关联转换为 plate_paths，出口关联转换为 door_path，移动平台、传送门和颜色记录器使用其命名字段。网页关联线为查看用，节点引用按原有方向导入。颜色记录器会挂为目标机关的子节点。旧大块地形按其覆盖网格铺砖。

当前导入器支持 PNG 及裁切、组件尺寸和上述关联。自定义碰撞矩形、多边形、背景参考图、图层排序、实例旋转翻转和章节清单自动接入尚需扩展。首次导入请在 Godot 检查这些内容；网页 JSON 和项目包仍完整保留设计数据。
